<h1>Jogo Número Secreto</h1>
<p>&#9888; Projeto desenvolvido afim de estudos com Alura.<br></p>
<p>Para este projeto, foi fornecido todo o código HTML e CSS e arquivos de imagens e sons. O desafio proposto foi estruturar todo o JavaScript da página para que ela funcionasse como no modelo apresentado previamente.</p>

<h2>Sobre o Projeto</h2>
<p>Este projeto é uma página web de um jogo de advinhar o número escolhido aleatoriamente pelo programa. Ao acertar o número, é exibida uma mensagem parabenizando e informando o número de tentativas gasta, também fica liberado o botão para começar uma nova rodada. O projeto conta com uma voz que fala o texto exibido na tela para fins de acessibilidade.</p>
